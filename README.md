# 🎵 Spotify Clone

A simple Spotify Clone built using HTML and CSS that recreates the layout and design of the Spotify web player.

## ✨ Features

* Responsive Layout
* Sidebar Navigation
* Music Cards
* Header Section
* Playlist Section
* Modern UI Design

## 🛠 Technologies Used

* HTML5
* CSS3
